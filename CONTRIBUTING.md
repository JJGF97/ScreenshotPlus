# Contribuir a ScreenshotPlus

¡Gracias por tu interés en ayudar a mejorar este proyecto! 🎉

## Reportar un bug o proponer una idea

Abre un [Issue](../../issues/new) describiendo:
- Qué esperabas que pasara.
- Qué pasó en realidad.
- Pasos para reproducirlo (si es un bug).
- Versión de macOS que estás usando.

No necesitas saber programar para esto — un buen reporte ya es una contribución valiosa.

## Proponer un cambio de código (Pull Request)

1. Haz un **fork** de este repositorio.
2. Crea una rama para tu cambio: `git checkout -b mi-mejora`.
3. Haz tus cambios y pruébalos localmente (`⌘R` en Xcode).
4. Sube tu rama y abre un **Pull Request** hacia `main`, explicando brevemente qué resuelve o mejora tu cambio.
5. Espera la revisión — puede que pida ajustes antes de aceptarlo, o lo apruebe directamente.

## Estilo de código

- Sigue el estilo ya usado en el proyecto (nombres descriptivos en inglés para el código, comentarios en español están bien).
- Si agregas una función nueva, un comentario breve explicando su propósito es bienvenido.

## ¿Dudas?

Abre un Issue con la etiqueta `question` y con gusto se responde ahí.
